# Home Assistant blueprints

Blueprints from my own Home Assistant setup, tidied up so anyone can use them. Each folder has the blueprint, a README and a one-click import button.

| Blueprint | What it does |
|---|---|
| [Restart-proof auto-off](restart_proof_auto_off/) | Turns a device off after a set time, and keeps counting through Home Assistant restarts and updates. Uses a restored timer helper instead of a `delay`. |

## Installing

Open a blueprint's folder and click **Import Blueprint**, or in Home Assistant go to Settings → Automations & scenes → Blueprints → Import blueprint and paste the link to the `.yaml` file.
